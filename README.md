## 📌 Ringkasan Proyek

Website ini dibangun sebagai media informasi dan katalog digital terpadu untuk memperkenalkan serta menampilkan empat pilar unit usaha yang dikelola oleh **IT Solution (ITS)** di lingkungan kampus:

1. **Unit F&B (Food & Drink):** Minuman dingin, camilan, dan perlengkapan darurat mahasiswa.
2. **Unit Percetakan & Dokumen:** Print hitam putih/warna, cetak amplop, jilid dokumen, stiker, dan sertifikat.
3. **Unit Konsinyasi:** Fasilitas titip jual produk kuliner mahasiswa dan kerja sama resmi dengan mitra luar (UMKM/Brand).
4. **Unit Jasa Kreatif:** Layanan multimedia mahasiswa mencakup desain grafis, fotografi, dan videografi.

---

## 🛠️ Standar Teknologi & Kepatuhan Tugas

Sesuai instruksi dan modul tugas kuliah, proyek ini dibangun dengan standar kode murni tanpa ketergantungan framework:

| Komponen | Spesifikasi | Keterangan |
| :--- | :--- | :--- |
| **Markup** | **HTML5 Semantik** (`index.html`) | Menggunakan tag semantik `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`, `<h1>`, `<p>`, dsb. |
| **Styling** | **Pure CSS3 Eksternal** (`style.css`) | Custom CSS Variables, Flexbox, CSS Grid, Glassmorphism, Responsive Media Queries. **Tanpa Bootstrap / Tailwind**. |
| **Logika** | **Vanilla JavaScript ES6+** (`script.js`) | Mobile menu toggle, ScrollSpy, catalog filter & real-time search, realtime WITA clock, live operational status, modal lightbox, scroll reveal. **Tanpa framework JS**. |
| **Tipografi** | Google Fonts CDN | *Plus Jakarta Sans* (Body Text) & *Space Grotesk* (Headings & Accents). |
| **Ikon** | Lucide Icons CDN | Format SVG bersih dan modern via `<script src="https://unpkg.com/lucide@latest"></script>`. |

## ⚡ Fitur Interaktif JavaScript

1. **Sticky Navbar & Glassmorphism Blur:** Navbar berubah transparan-buram dengan elevasi bayangan saat digulir ke bawah.
2. **Mobile Navigation Drawer:** Menu navigasi responsif dengan tombol hamburger animasi, penutup otomatis saat klik link, dan pencegahan scroll latar.
3. **ScrollSpy Navigation:** Menu aktif berpindah otomatis mengikuti posisi scroll pengguna.
4. **Smooth Scroll:** Perpindahan halus antar-section dengan kompensasi tinggi sticky header.
5. **Katalog F&B Filter & Real-Time Search:**
   - Filter tab kategori *(Semua, Minuman, Makanan, Lainnya)* dengan badge jumlah item.
   - Live search input untuk mencari produk secara instan berdasarkan nama.
   - Status produk kosong (*Empty state*) dengan tombol reset filter.
6. **Modal Lightbox Foto Daftar Harga:** Tombol "Foto Daftar Harga Asli" untuk membuka preview gambar fisik `Daftar Harga.jpeg`.
7. **Real-Time WITA Clock & Automatic Operational Status:** Menghitung waktu WITA (UTC+8) dan menentukan apakah stand ITS sedang buka atau tutup secara dinamis.
8. **WhatsApp Action Hub:** Tombol kontak dengan pesan otomatis siap kirim sesuai kebutuhan *(Tanya F&B, Pesan Print, Pengajuan Konsinyasi, Jasa Kreatif)*.
9. **Back to Top Floating Button:** Tombol melayang yang muncul saat layar digulir melebihi 400px.
10. **Scroll Reveal Animation:** Animasi masuk halus saat elemen muncul di viewport pengguna.

## 🚀 Panduan Menjalankan & Deployment

### 1. Membuka di Local Browser
- Cukup buka file `index.html` langsung dengan klik dua kali pada browser pilihan Anda (Google Chrome, Microsoft Edge, Firefox).

### 2. Menggunakan VS Code Live Server
1. Buka folder `Landing Page ITSolution` di Visual Studio Code.
2. Klik kanan pada `index.html`.
3. Pilih **"Open with Live Server"**.
4. Website akan berjalan di `http://127.0.0.1:5500/index.html`.

### 3. Deployment ke GitHub Pages
1. Inisialisasi git repository atau upload berkas ke repositori GitHub:
   ```bash
   git init
   git add .
   git commit -m "feat: landing page katalog digital IT Solution HMP-TI"
   git branch -M main
   git remote add origin <URL_REPOSITORY_ANDA>
   git push -u origin main
   ```
2. Buka repository di GitHub -> Masuk ke menu **Settings** -> **Pages**.
3. Pada bagian **Build and deployment**, pilih branch `main` dan folder `/ (root)`.
4. Klik **Save**. Dalam 1-2 menit, landing page akan aktif di tautan GitHub Pages Anda.
